# 履歴とダウンロードの削除（0.14.0）

履歴の行とランダム再生ボタン、ダウンロードのアルバム・プレイリストの行と開くボタンに長押しの削除操作を追加した。確認画面でキャンセルした場合は変更しない。通常の検索やライブラリの登録済み項目にこの削除操作は付けない。

## 履歴

HistoryRecords.removeは種類とIDの組を使い、該当する登録をすべて削除する。残る項目の再生時刻と順序を保持する。HistoryStoreは記録と同じロック内で現在のアカウントのSharedPreferencesへcommitし、既存の変更通知で表示を更新する。次に同じ項目を再生すると再び履歴に登録する。

## ダウンロード

DownloadCategoryをALBUMS / PLAYLISTSの2種類に限定した。旧版のTRACKS / ARTISTSや無効な画面状態はALBUMSへ移行する。検索の楽曲・アーティストタブは維持する。

SavedCollections.removalは保存済み曲、コレクションの全ページの登録情報、旧版の曲ごとの保存元から所属を組み立てる。対象だけに属する保存曲を削除し、ほかのアルバム・プレイリストにも属する曲は削除をスキップする。保存元が削除対象を指している共有曲は、残すコレクションへ参照先を更新する。音質・保存日時・音声表現・キャッシュは保持する。これにより削除済みの項目が旧版互換の一覧復元で再表示されることを防ぐ。

共有曲の参照先の更新、専用曲の削除、対象のコレクション索引の削除を順に行う。共有判定に必要な索引が破損している場合は削除を中止する。ダウンロード中は削除を受け付けず、ダウンロード開始ともロックで排他する。削除対象のアカウントは確認画面を開いた時点で保持し、処理中のアカウント切り替えで別の保存先を削除しない。

保存曲の削除は完成マーカーを無効にしてから、使用されていないキャッシュとマニフェストを除去する。再生中のSavedAudioが参照している音源は保持し、最後の参照が閉じた時点で後始末する。削除待ちの印をディスクに残すため、アプリ終了で後始末が中断されても、次の保存一覧の読み込みで再開できる。再ダウンロードが完了した場合は新しい完成データを保持する。

一覧の読み込みと一括削除は専用の実行スレッドで行う。通信を待っている検索処理や、画面の描画を妨げない。削除結果は削除曲数と共有のため保持した曲数で表示する。Amazon上のプレイリストを編集・削除する通信は行わない。

## 検証方法

ユニットテストで履歴の種類別削除・順序・再登録、旧タブの移行、共有・専用曲の判定、旧版の保存元、削除済み項目の再表示防止、音質情報の保持を検証する。

通常のAndroid Instrumentationには、隔離したアカウントの合成マニフェストと端末内のバイト列を使うOfflineDeletionVerificationを追加した。共有曲と別アカウントのキャッシュ保持、専用曲の実キャッシュ削除、参照中の削除と参照終了後の掃除、中断された削除の再開を確認する。音声のHTTP取得やAmazonのデータ変更は行わない。

`adb.exe shell am instrument -w -e uiLocalDeletion true jp.nao.amclient.test/jp.nao.amclient.PlaybackVerification`で、実際のMainActivityの長押し、確認画面のキャンセル／削除、共有曲の保持、一覧と空表示の更新、検索タブの維持を検証する。この検証は専用の隔離したデータだけを使用し、finallyで元のアカウントスコープを復元する。
