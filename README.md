# AM Client for Android 0.14.0

Amazon Music 日本版の Web 通信を調査して作成した、非公式のネイティブ Android クライアントです。曲一覧・検索・再生画面は Android の View、音声再生は Media3 / ExoPlayer で実装しています。公式 Web プレイヤーの HTML / JavaScript は読み込みません。ログイン時だけ Amazon の認証ページを WebView で開きます。

**検証段階の実装です。** Pixel 10 Pro の Prime アカウントでネイティブ DRM 再生を確認しています。音声データは暗号化されたまま保存し、保存後の再生にもオンラインの認証とライセンス取得を使います。完全オフラインの再生には対応していません。Web 用の非公開 API に依存するため、Amazon の変更で利用できなくなる可能性があります。

## 機能

- ネイティブの検索・ライブラリ一覧、サムネイル、再生中の曲名・アーティスト・ジャケット表示
- 下部の「検索・ライブラリ・ダウンロード」ナビゲーション、共通ミニプレイヤー、再生詳細画面
- 検索結果の「楽曲・アルバム・プレイリスト・アーティスト」タブ切り替え
- ライブラリの「履歴・アルバム・プレイリスト」タブ、登録済み項目の追加ページ取得、自作・フォロー中プレイリストの表示
- アルバムの「いいね」と他者のプレイリストのフォローを追加・解除。公式Webと同じ登録内容をライブラリに反映
- ライブラリから自作プレイリストを作成・名前変更・削除。曲の検索追加、登録ごとの削除、上下への並べ替え
- アプリ内の再生履歴をアカウント別に最大50件保存し、重複をまとめて新しい順に表示。アルバム・プレイリスト・アーティストを履歴からランダム再生。項目を長押しして履歴から削除
- 再生中の曲から再生元のアルバム・プレイリストの曲一覧とアーティストページへ移動
- アーティストのランダム再生、アルバム一覧と関連プレイリスト一覧、追加ページの読み込み
- サーバー管理の再生キューと、契約に応じた曲送り・シークの制御
- 「曲を選んで再生」に対応するアルバム・プレイリストのシャッフル、全曲リピート、1曲リピート
- Media3 と Android Widevine CDM による DASH 音声再生
- バックグラウンドの再生サービスとメディア通知、通知・ロック画面からの再生 / 一時停止・前後の曲への操作（契約で許可される操作のみ）
- 選曲可能な再生での、通知・ロック画面からのシャッフル切り替えとリピート切り替え
- アルバム・プレイリストの全曲ダウンロード、進捗・中止、保存済み音源の再利用、項目の長押しで保存データを削除。ほかの保存済みアルバム・プレイリストと共有する曲は保持
- ダウンロード内の「アルバム・プレイリスト」タブ、保存元の曲一覧を開いて再生
- 再生音質と保存音質の個別設定（節約 48 / 標準 192 / 高音質 320 kbps）、再生位置を保った音質変更
- 音量ノーマライズと基準音量の設定（−30〜−14 LUFS、初期値 −20 LUFS）。保存音源とストリーミングの両方に適用

アルバム・プレイリストの曲一覧にある「ダウンロード」で、全ページの曲を順に保存します。暗号化されたDASH音源とマニフェストだけをアプリ内に保存し、音声ファイルへの変換や再生音のキャプチャは行いません。

保存後も通常の認証・再生キュー・ストリーミングライセンスを使います。サーバーが選んだ曲に保存データがあれば、その音声は端末から読み込みます。認証・ライセンス取得・再生状態の送信には通信が必要です。「ダウンロード」一覧からの再生は保存データだけを使い、Amazonが別の未保存曲を選んだ場合は理由を表示します。検索やアルバム・プレイリストからの通常再生では、未保存の曲は従来どおりストリーミングします。 履歴・検索・ライブラリ・アーティストページからも、保存済みなら音質設定にかかわらず保存した音源を使います。再生音質の設定は未保存曲のストリーミングに適用します。

## インストール

`dist/am-client-debug.apk` が最新版、`dist/am-client-webview-0.1.0.apk` は前版の控えです。

1. Android 8.0 以上の端末に APK をインストールします（開発用署名）。
2. 「アカウント」→「ログイン / アカウントを変更」でログインします。
3. 下部の「検索」「ライブラリ」から曲やプレイリストを選びます。Prime などの契約では Amazon 側の選曲となる場合があります。ミニプレイヤーの曲名をタップすると、シーク・シャッフル・リピートを操作する再生詳細が開きます。
4. アルバム・プレイリストの曲一覧を開き、「ダウンロード」を押します。通知と曲一覧で進捗を確認でき、同じボタンや通知から中止できます。再試行では完了済みの曲を再取得しません。
5. 「ダウンロード」タブで保存済みのアルバム・プレイリストを開き、曲を再生します。項目を長押しすると、確認後に端末の保存データを削除します。他の保存済み項目と共有する曲は残します。再生にはインターネット接続が必要です。

「ライブラリ」→「履歴」の項目も、長押しして確認すると履歴から削除できます。再び再生した項目は、新しい履歴として表示されます。

セッションは端末内に保持します。PC のログイン情報は APK に含まれません。認証画面には Android System WebView が必要です。

再生詳細のシャッフルアイコンで曲順を切り替えます。リピートアイコンは押すたびに OFF → アルバム（プレイリストでは全曲）→ 1曲 → OFF と切り替わります。Amazon が許可しない操作は無効になります。新しいアルバム・プレイリストを再生すると、両設定は OFF から始まります。

ライブラリの「プレイリスト」にある「＋ プレイリストを作成」で、非公開の自作プレイリストを作成できます。既存の自作プレイリストは曲一覧の「編集」から開きます。「曲を追加」で楽曲を検索して追加し、曲ごとの「編集」で上下移動・削除、右上の「メニュー」で名前変更・プレイリスト削除を行えます。変更はAmazon Musicのアカウントに反映されます。削除には確認画面があり、公式・フォロー中のプレイリストや「My いいね」は編集対象に含めません。操作の可否は現在のサーバー権限に従います。

アルバム・他者のプレイリストの曲一覧にある「＋ ライブラリに追加」で、Amazon Music側にも登録します。「✓ ライブラリ追加済み」を押して確認すると登録を解除できます。解除後も端末のダウンロードは残ります。ライブラリのアルバムタブには、公式Webと同じ「いいねしたアルバム」を表示します。自作プレイリスト・Myいいね・個人向けミックスにはこのボタンを表示しません。

## ビルド

JDK 17 と Android SDK (platform 35 / build-tools 35.0.0) を用意し、`local.properties` に `sdk.dir=/path/to/Android/Sdk` を指定してください。

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
adb.exe install -r app/build/outputs/apk/debug/app-debug.apk
```

Gradle 8.11.1 / AGP 8.9.1 / Media3 1.5.1。リリース配布の署名設定は別途必要です。

## 制限と未確認点

- Amazon の公式開発者 API はクローズドベータです。本実装は、承認済み開発者 API を利用した製品ではありません。
- 永続ライセンスは取得できていません。保存した音源も完全オフラインでは再生できません。保存後の権限・カタログ変更や、長期間経過した音源の再生は保証できません。
- 広告・音声案内などの特殊なキュー項目、無限スクロール、歌詞には未対応です。
- ライブラリのアルバム・プレイリストはAmazonの登録済み項目です。履歴はこのアプリでの再生を端末内に記録します。Amazon側の過去の再生履歴は取り込みません。
- 同時ダウンロードは1つのアルバムまたはプレイリストです。曲ごとに保存し、中断後も完了した曲は残ります。再生不可の曲と通信などで失敗した曲は件数を区別して表示し、元の一覧から再試行できます。
- 認証ページと非公開 API の更新、端末の Widevine 対応により動作しない場合があります。

調査の観測結果と実装の根拠は `docs/analysis.md`、検証結果は `docs/validation.md` に記載します。

再生用・保存用の音質変更に関する追加調査は [音質変更の調査](docs/audio-quality.md) に記載します。

自作プレイリストの編集仕様と調査・検証方法は [プレイリスト編集](docs/playlist-editing.md) に記載します。

履歴・ダウンロードの長押し削除と共有曲の扱いは [端末内データの削除](docs/local-deletion.md) に記載します。

ライブラリへの追加・解除の公式仕様と実装は [ライブラリへの登録](docs/library-membership.md) に記載します。

## 0.2.1 の修正

Prime にも無条件で有効にしていた音源 ASIN の自動置換を、Unlimited / Unlimited HD のみに制限しました。Prime の楽曲が別の契約向けの音源に置き換わり、ライセンス取得で拒否されて 30 秒で停止する問題への修正です。ライセンス取得前の clear lead 再生も無効にしました。

開発用ビルドでは `adb shell dumpsys activity service jp.nao.amclient/.PlaybackService` で再生位置とエラー状態を確認できます。認証情報や復号鍵は出力しません。

## 0.3.0 の変更

検索結果を楽曲・アルバム・プレイリストで切り替え、各項目にジャケットを表示します。同じ検索のタブ切り替えでは再通信せず、表示中の行の画像を非同期で読み込んでメモリー内にキャッシュします。

MediaSession にサーバー管理の前後移動を接続し、Android の通知・ロック画面のメディア操作から曲送りできるようにしました。Media3 の状態通知を扱うアダプターに変更し、タイトル・アーティスト・曲 ID・ジャケットを新しい曲に合わせて反映します。

## 0.4.0 の変更

サーバーのキュー / 楽曲の capabilities に基づき、シャッフル・全曲リピート・1曲リピートを有効にします。Prime の All-Access プレイリストも同じ判定で対応します。設定は公式 Web と同じキュー更新 API に送信し、成功後に画面と MediaSession に反映します。変更中も音声は継続し、サーバーに拒否された設定は確定しません。

曲を選べるアルバム・プレイリストは末尾でおすすめ曲に進まない設定にしました。全曲リピートでは末尾から先頭へ、1曲リピートでは同じ曲へ戻ります。1曲リピート中の手動の前後移動では、サーバーのループを一時解除して移動し、新しい曲の再生状態を送信してから1曲リピートを戻します。

## 0.4.1 の変更

検索結果のアルバム・プレイリストの右側に「曲を選んで再生」を表示します。検索 API が返す `playParams.selections` に `PLAY` がある項目が対象です。追加の通信は行いません。

## 0.4.2 の変更

「曲を選んで再生」をタイトル下の補足行へ移動しました。「プレイリスト　曲を選んで再生」のように、既存の補足テキストのすぐ右側に色を変えて表示します。

## 0.5.0 の変更

再生中のタイトル・ジャケット部分をタップすると、その曲が入ったアルバムの曲一覧を開きます。再生中の曲を強調表示し、共同アーティストもそれぞれリンクから開けます。曲が変わると、表示中のアルバムとアーティストの情報も更新します。

検索に「アーティスト」タブを追加しました。アーティストページには、ランダム再生と「アルバム・プレイリスト」のタブ、さらに表示ボタンを用意しています。アルバムやプレイリストを開くと収録曲を閲覧でき、画面を移動しながら再生・一時停止・曲送りを操作できます。

アルバム・プレイリスト内の曲を再生する際は、その一覧の文脈で Amazon が返した再生操作を使います。曲を選べない場合はシャッフル / おまかせ、再生できない項目は再生不可として表示します。アーティストのランダム再生も正規の再生キューとライセンスを使用します。

今回の Prime アカウントでは、アーティストのランダム再生に関連アーティストの曲も含まれました。公式 Web と同じ要求で同様の選曲になることを確認しており、アプリで指定アーティストだけに強制していません。

## 0.5.1 の変更

検索結果のアルバム・プレイリストをタップすると、アーティストページから開く場合と同じ曲一覧に移動します。右側のボタンも「開く」に変更しました。一覧を開いてから、全曲再生や各曲の再生を選べます。

## 0.5.2 の変更

再生中の曲をタップすると、再生元に応じた曲一覧を開きます。プレイリストからの再生ではそのプレイリスト、アルバムからの再生ではそのアルバムを表示します。曲単体やアーティストのランダム再生など、再生元の一覧がない場合は現在の曲のアルバムを表示します。

全曲再生でも一覧内の曲を選んだ場合でも、再生元の種類とIDを保持します。曲送り後も元の一覧を使い、同じ曲を別の一覧から再生し直したときは表示先を切り替えます。表示中に再生元が変わった場合も更新し、プレイリストの「さらに表示」も利用できます。

## 0.6.0 の変更

ライブラリを楽曲・アルバム・プレイリストの3タブに変更。カテゴリ別の登録済み項目を50件ずつ取得し、「さらに表示」で続きへ進みます。プレイリストは自作とフォロー中をまとめ、重複を除きます。アルバムとプレイリストは検索結果と同じ曲一覧を開きます。検索とライブラリの選択タブはそれぞれ保持します。

保存用ライセンスの拒否を識別し、同じ要求の自動再試行を停止。通信失敗とは区別して画面に即時反映します。プロセス終了後の「確認中」表示、保存完了前の失敗時の後片付け、二重実行も見直しました。これは保存失敗の原因調査と状態表示の修正であり、ダウンロード成功を示すものではありません。

## 0.7.0 の変更

ユーザーの指定により、再生音の録音ではなく暗号化された配信データを保存する方式に変更しました。再生時に通信が必要なことについて了承を受けています。

アルバム・プレイリストのページに一括ダウンロードと中止を追加し、メイン画面の再生中の曲の下にあった保存ボタンは削除しました。保存済みの曲を通常のキューで再生する場合も保存音源を優先します。キャッシュはアカウント・曲ごとに分離し、削除や失敗時の後片付けが他の保存曲に影響しない構成です。同じ曲を選曲可能なプレイリストからも保存した場合、音声を再取得せずにその再生元の情報を保持します。

## 0.7.1 の変更

保存結果の「再生には通信が必要です。」と曲の補足の「（通信が必要）」を削除し、プレイヤーの「保存音源から再生（通信あり）」を「保存音源」に短縮しました。旧版で記録された保存結果も表示時に整えます。

ダウンロード一覧に楽曲・アルバム・プレイリストの3タブを追加しました。アルバム・プレイリストは共通の曲一覧画面を開きます。これまで保存した曲からも再生元を拾い、新しく保存する一覧は曲と独立して所属情報を保持します。同じ曲が複数の一覧にあっても、片方の一覧が消えないようにします。音源の保存・認証・ライセンス処理は従来と同じです。

## 0.8.0 の変更

曲末から次の音源を取得している間は、MediaSessionをバッファリング状態として維持します。途中で前景サービスが解除され、バックグラウンドからの再開をAndroidに拒否されて通知の曲名が古いままになる問題を修正しました。実際のキュー末尾では終了を公開し、準備中に一時停止された場合もその操作を引き継ぎます。

再生ウィジェットにシャッフルとリピートのボタンを追加しました。許可された再生でのみ表示し、リピートはOFF→全曲→1曲→OFFのうち利用可能なモードを循環します。サーバーで設定が確定してから、状態とアイコンを更新します。これまでのMediaControllerの通常のシャッフル・リピート設定も引き続き利用できます。


## 0.9.0 の変更

メイン画面と曲一覧の上部に「音質」を追加しました。「再生音質」「保存音質」を個別に設定でき、節約 48 kbps / 標準 192 kbps / 高音質 320 kbps から選べます。初期設定は両方とも標準です。対象は標準音質の Opus で、HD / Ultra HD は含めません。

シーク可能な曲は、再生中でも位置と再生・一時停止の状態を維持して音質を切り替えます。読み込みが発生する場合があります。シークが許可されない再生は次の曲から適用します。再生表示とダウンロード内の楽曲行には実際の音質を表示します。楽曲に希望の候補がない場合は、利用できる候補を選びます。

保存音質は次のダウンロードから適用します。保存済みの曲を変更する場合は、元のアルバム・プレイリストで再度ダウンロードしてください。同じ保存音質の曲は再取得を省略し、変更がある曲だけ保存し直します。完了するまで旧データを維持し、中止・失敗では元の保存曲を残します。再生中に保存し直した場合も、その再生は旧データで継続します。

0.9.0では「ダウンロード」からは保存された音質で再生し、通常再生では指定音質に合う保存データだけを再利用していました。この条件は0.10.1で変更し、すべての導線で保存音源を優先します。旧版で保存した48 kbps音源も引き続き利用できます。


## 0.10.0 の変更

ライブラリの「楽曲」を「履歴」に変更しました。この更新以降にアプリで再生したアルバム・プレイリスト・アーティストを記録します。同じ種類とIDの項目は最新の1件にまとめ、新しい順で最大50件を保持します。アカウントごとに端末へ保存し、再起動後も残ります。

履歴の「ランダム再生」は現在の再生権限を取得してから開始します。タイトル部分は曲一覧やアーティストページを開きます。一覧を開いただけの項目や、再生に失敗した項目は履歴へ追加しません。曲一覧から曲を選んだ場合も元の一覧を記録し、アーティストのランダム再生では選曲された曲のアルバムと区別してアーティストを記録します。検索・ダウンロードの「楽曲」タブは従来どおり利用できます。

ダウンロード内のアルバム・プレイリストからの再生を、保存音源だけを使う経路へ修正しました。保存音質と通常の再生音質が異なっても保存した音質を使い、全曲再生・曲の選択・前後の移動・自動曲送りでも維持します。再生中の曲から開く元の一覧でも同じ扱いです。未保存曲や保存データの不足を理由に、音声のストリーミングへ自動的に切り替えることはありません。

保存音源の再生中に「再生音質」を変更した場合は、通常再生用の設定だけを変更します。その保存曲の音質を変える場合は「保存音質」を変更して再ダウンロードしてください。認証・ライセンス取得・再生状態の送信に関する通信は従来どおりです。


## 0.10.1 の変更

保存音源の優先をすべての再生導線に適用しました。履歴のランダム再生・履歴から開いた曲一覧・検索結果・ライブラリ・アーティストページ・再生中の曲から開く一覧で、Amazonが選んだ曲の保存音源があれば、その音質を使います。前後の曲への移動とバックグラウンドの自動曲送りも同じ選択処理を使います。

通常の再生は未保存曲だけストリーミングします。ダウンロード一覧からの再生は、従来どおり保存音源だけを使います。保存音源の再生中に「再生音質」を変更しても、現在の保存音源を継続し、設定は未保存曲のストリーミングに適用します。保存した音質そのものを変える場合は、保存音質を変更して再ダウンロードしてください。

## 0.11.0 の変更

画面上部の「設定」→「音量ノーマライズ」からオン／オフと基準音量を変更できます。初期設定はオン・−20 LUFS。数値を小さくすると音量が小さくなり、設定は再生中にも滑らかに反映されます。再生音質・保存音質も同じ設定メニューにあります。

初めての曲は再生しながらK-weightingとゲート付きの音量測定を行い、最初の約3秒から徐々に補正します。30秒以上の有効な測定ができた曲は、その音量の統計値を端末内に最大500曲記録して次回の冒頭から使います。初回の補正は再生した範囲からの推定なので、曲全体を事前解析する方式とは異なります。静かな部分を含む曲では、測定が進むにつれて補正量も変わります。

音量補正は共通の再生経路に適用し、検索・履歴・ライブラリ・保存音源・バックグラウンド・曲送りでも動作します。音声ファイルの保存形式や保存音質は変更しません。ステレオの左右には同じ補正を適用し、増幅は最大12 dB、サンプルピークは−1 dBFSを上限に抑えます。ピーク制限や増幅上限のため基準に届かない曲もあります。端末のメディア音量は別に調整できます。

## 0.12.0 の変更

下部に「検索・ライブラリ・ダウンロード」を配置しました。検索欄は検索画面に表示し、カテゴリや入力中の文字を保って移動できます。アルバム・プレイリスト・アーティストのページからも、下部のタブで一覧へ戻れます。

各一覧の下部に共通のミニプレイヤーを表示します。曲名・アーティスト・ジャケットと再生／一時停止・次の曲の操作を1段にまとめ、未選曲時は非表示にします。曲名やジャケットをタップすると再生詳細が開きます。

再生詳細には大きなジャケット、再生位置、前後移動、シャッフル、全曲／1曲リピート、再生元の曲一覧とアーティストへのリンクを用意しました。共同アーティストは選択して開けます。権限に応じて操作を有効にし、シャッフルとリピートはサーバーの確定後に表示を更新します。曲一覧の表示先は従来どおり、元のプレイリストかアルバムで分岐します。

画面の開閉・移動は同じ再生サービスを使用し、音源を読み直しません。保存音源の優先、保存音源のみの再生、音質とノーマライズ、通知・バックグラウンドの再生操作も共通の処理を使います。


## 0.12.1 の変更

アカウントの操作を人のアイコンに変更しました。再生詳細のシャッフルとリピートもアイコンで表示し、OFFはグレー、有効な状態はアクセント色と背景で区別します。1曲リピートは中央に「1」を表示します。読み上げと長押しでは現在の状態を確認できます。

モード変更中の「再生設定を変更しています」という表示を削除しました。権限に応じた操作の有効／無効と、サーバー確定後の状態更新は従来どおりです。再生詳細の下部にあったアーティストボタンを削除し、曲名の下にあるアーティスト名からページを開きます。


## 0.12.2 の変更

プレイリストから再生している場合は、再生詳細に「プレイリストの曲一覧」と「アルバムの曲一覧」を並べて表示します。前者は元のプレイリスト、後者は現在の曲が収録されたアルバムを開きます。曲が変わるとアルバム側の移動先も更新します。アルバムからの再生では、従来どおり曲一覧へのリンクを1つ表示します。

ダウンロード一覧から開始した再生では、新しいアルバムページにも保存音源だけを使う設定を引き継ぎます。このページを開くだけで、ダウンロード一覧への追加や音源の取得は行いません。

## 0.15.1 の修正

プレイリストの表紙を選ぶ際、PRIMARY画像と正方形を優先し、横長のAmazon Musicロゴを誤って表示する問題を修正しました。既存の履歴・ダウンロード一覧も、表示時に表紙情報を更新します。音源の再保存は不要です。

曲ごとのSHUFFLE操作を「シャッフル再生」に統一しました。従来の「おまかせ」は関連曲も選ばれるSTATION操作だったため、「ステーション再生」に変更して区別します。
